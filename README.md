# BrilliantONYX Corporate Website

A professional, modern website for BrilliantONYX Contracting LLC, a premier construction and interior solutions provider based in Dubai, UAE. The website showcases our company's services, projects, and expertise in the construction and interior design industry.

<br clear="left"/>

## Overview

This website serves as the digital presence for BrilliantONYX, featuring:

- Company profile and services
- Portfolio of completed projects
- Client testimonials and partnerships
- Contact information and inquiry forms
- Privacy policy and terms of service

## Key Features

- **Professional Design**: Clean, modern interface reflecting our corporate identity
- **Responsive Layout**: Optimized viewing experience across all devices
- **Dynamic Content**: 
  - Automated image slideshow
  - Client logo showcase
  - Interactive project portfolio
- **User Experience**: 
  - Intuitive navigation
  - Mobile-friendly interface
  - Quick-access contact options
  - Project filtering system
  - Social media integration

## Maintenance

### Style Customization
The website uses CSS variables for consistent branding:

```css
:root {
    --primary-color: #8B1E65;
    --secondary-color: #666666;
}
```

### Typography
Corporate fonts are defined globally:
```css
:root {
    --heading-font: 'Morris Sans', system-ui;
    --body-font: 'Ubuntu', system-ui;
}
```
